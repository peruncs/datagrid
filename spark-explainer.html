Eclipse DataGrid · Aeron transport

The essentials, on one page

Fixed 1-writer / N-reader replication over Aeron reliable UDP plus Aeron Archive — a Kafka-free plugin with the same neutral SPI. Serializer bytes stay opaque; Aeron carries framing, order, and recovery.

1Key idea

Writer Store writeprepare → local enqueue → commit
→
Aeron MDC (live)one UDP stream, N readers
→
Archive (WAL)recording = replay source
→
Readersreplay → join live → import

Commit marker means durable in Archive + accepted locally — not Store fsync (Store 5.x only reports enqueue). Crash rule: every committed sequence replays exactly once, else startup fails closed with RESEED_REQUIRED.

2Key concepts

Envelope (wire)64-byte header + one chunk: cluster, epoch, sequence, kind, offsets, CRC32C. Markers COMMIT/ABORT carry no payload.
Prepare / commit / abortChunks stage by sequence; readers apply only after a matching commit checksum validates.
Recording + ExtendWriter records one Archive recording; restarts extend the same recording (term/MTU/stream validated).
Cursors & checkpointsAtomic temp-file + force + rename + CRC files bound to cluster/node/generation/epoch/recording.
CRC32C ≠ securityDetects corruption and assembler bugs. Forgeable by any sender — never a trust root, never a purge watermark alone.
Provider SPIKafka and Aeron are interchangeable plugins behind ClusterReplicationTransport; retention stays disabled for Aeron until ACKs are authenticated.

3Write path (prepare → enqueue → commit)

write(data)
  coordinator.prepare(data)      // chunks → Aeron (dictionary first)
  delegate.write(data)           // local Store enqueue
  coordinator.commit(prepared)   // COMMIT marker → await Archive recorded
  on local failure  → abort(sequence)      // readers discard staged chunks
  on commit failure → COMMITTING_UNCERTAIN  // fail closed, reseed on restart

Durability modes: ARCHIVE_FIRST (prepare before enqueue) vs ENQUEUE_THEN_ARCHIVE (enqueue first; wider uncertainty window). LOCAL_DURABLE_FIRST is rejected — Store exposes no durable-completion callback.

4Read path (replay → live → import)

PersistentSubscription (recordingId, startPosition)
  decodeView → validate (cluster/epoch/sequence/bounds/CRC)
  stage chunks in native buffers (TransactionAssembler)
  on COMMIT → verify witness CRC → import → materialize → persist cursor
  cursor advances only after Store import (at-most-once boundary)

off-heap Store bytes travel in native buffers end-to-end; heap holds only headers, counters, and checkpoints.

6What is intentionally deferred not in v1

Leader election / failover / fencing · ACK-driven Archive purge (ACKs unauthenticated) · async checkpoint batching · crash/tail-replay matrix · reader backpressure bounds · Lucene/vector convergence proof. Each needs its own design and gating tests.
